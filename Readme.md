<!-- Tailwind Css Rule -->
Rule yaad rakhne ka shortcut
@layer base → HTML tags (body, h1, p, a, input, button)
@layer components → Reusable UI classes (.btn, .card, .navbar)
@layer utilities → Chhoti helper classes (.text-balance, .scrollbar-hide, .rotate-y-180)

Isi structure ko follow karna Tailwind projects me best practice mana jata hai.
